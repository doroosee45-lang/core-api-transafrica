# Internationalisation — contrat pour le web et le mobile

Décision V-03 (21/11/2026) : **français par défaut** dans les 5 pays, **anglais disponible partout**, le **choix de l'utilisateur prime**.

## Langue d'une réponse

1. Utilisateur connecté : `identity.profiles.preferred_language` (`fr` | `en`), modifiable par `PATCH /api/v1/identity/me { "preferred_language": "en" }` — effet immédiat.
2. Visiteur : en-tête `Accept-Language` (négociation par poids `q`).
3. Sinon : `fr`.

Chaque réponse porte `Content-Language` et `meta.locale`. **Les applications doivent enregistrer le choix de langue de l'utilisateur via `PATCH /identity/me`**, pas seulement l'envoyer en en-tête.

## Ce qui est traduit / ce qui reste neutre

| Élément | Traitement |
|---|---|
| Messages d'erreur (`error.message`) | Traduits ; `error.code` est stable et indépendant de la langue — l'interface doit se baser sur le code |
| Erreurs de validation (`error.details[].message`) | Traduits (messages Zod localisés + messages métier) |
| Libellés de statuts (`status_label`) | Traduits dans les réponses client ; référentiel complet bilingue : `GET /api/v1/i18n` |
| Notifications (centre, e-mail) | Rédigées dans la langue de CHAQUE destinataire au moment de l'envoi |
| Dates | API : ISO 8601 UTC ; notifications : heure locale du lieu (fuseau IANA de l'aéroport ou de l'agence) avec décalage explicite |
| Montants | API : chaîne décimale + code devise (jamais de conversion implicite) ; notifications : formatés selon langue et pays (`Intl`) |
| Annonces générales | Texte FR obligatoire, version EN facultative (`translations.en`) |
| Invitations | E-mail bilingue (langue du destinataire encore inconnue) |

## Référentiel partagé

`GET /api/v1/i18n` (public) : langues prises en charge, paramètres des pays (`default_locale`, `supported_locales`, fuseau, devise, indicatif) et libellés FR/EN de tous les statuts (colis, expéditions, vols, devis, paiements, demandes, réclamations, catégories, types de documents). **Le web et le mobile doivent utiliser ce référentiel** plutôt que de dupliquer les traductions.

## Paramètres par pays

`GET|PATCH /api/v1/canada/countries/{code}/settings` (`canada.settings.read|manage`, périmètre du pays) : langue par défaut, langues proposées, fuseau par défaut. La devise par défaut relève de la gouvernance financière globale.

## Garantie de complétude

`tests/i18n.test.ts` extrait statiquement tous les messages du code (`src/i18n/extract.ts`) et échoue si un seul n'a pas sa traduction anglaise ; idem pour les règles levées par les triggers SQL et les libellés de statuts.
